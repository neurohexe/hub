📋 Массовое добавление ассортимента

Вставьте товары, по одному на строку.
Можно просто название, а можно через " / " добавить единицу, остаток на складе и поставщика — порядок частей неважен, число всегда распознаётся как остаток (запятую внутри названия — например "2,5%" — можно не бояться):
Ножницы — только название
Ножницы / штука — название + единица
Ножницы / 14 / штук — название + остаток (14) + единица
Молоко 2,5% / л / ООО Молоко — название + единица + поставщик
AI сам определит склад (Продукты / Хозтовары / Канцелярия / Медикаменты) и категорию, при необходимости создаст новую категорию на нужном складе.
